# 🧠 Algorithms

## What is an Algorithm?

An **algorithm** is a set of well-defined instructions to solve a particular problem.

---

# 🍳 Recipe Analogy

```text
+----------------+      +----------------+      +----------------+
|  Ingredients   | ---> |     Recipe     | ---> |   Tasty Dish   |
+----------------+      +----------------+      +----------------+
```

### 🍜 Cup Noodles Example

```text
+-----------------------+      +-------------------------------+      +------------------+
|         INPUT         | ---> |          ALGORITHM            | ---> |      OUTPUT      |
+-----------------------+      +-------------------------------+      +------------------+
| 🍜 Cup of noodles     |      | 1. Boil water                 |      | 🍜 Tasty noodles |
| 🧂 Taste maker        |      | 2. Pour water into cup        |      +------------------+
| 💧 Water              |      | 3. Add taste maker            |
+-----------------------+      | 4. Close lid and wait 4 mins  |
                               +-------------------------------+
```

# 💻 Programming Example

### Algorithm to Add Two Numbers

```text
+------------------+      +----------------------------+      +----------------+
|      INPUT       | ---> |         ALGORITHM          | ---> |     OUTPUT     |
+------------------+      +----------------------------+      +----------------+
| a                |      | 1. sum = a + b             |      | sum            |
| b                |      | 2. Return sum              |      +----------------+
+------------------+      +----------------------------+
```

---

# ✨ Characteristics

- Well-defined inputs and outputs
- Each step is clear and unambiguous
- Language independent

---

# ❓ Why Learn Algorithms?

- Developers solve problems every day.
- Algorithms provide techniques for solving those problems.
- A single problem can have multiple algorithmic solutions.
- Each algorithm has different performance trade-offs.
